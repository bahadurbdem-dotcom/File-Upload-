    যেকোনো ঘর আলাদাভাবে বদলানো যায় — খালি রাখলে আগেরটাই থাকবে। সেভ করলে সাথে সাথে নতুন করে কানেক্ট হবে; ব্যর্থ হলে আগের সেটিংসে ফিরে যাবে।

    API ID ও Hash পাবেন my.telegram.org → API development tools থেকে।
    @BotFather থেকে নেওয়া টোকেন।
    প্রাইভেট গ্রুপ/সুপারগ্রুপ। বটকে অ্যাডমিন করুন (Post, Delete, Pin অনুমতিসহ)। আইডি পেতে গ্রুপের মেসেজ @getidsbot-এ ফরওয়ার্ড করুন।
    গ্রুপ বদলালে আগের গ্রুপের ফাইলের লিংক অচল হবে (ফাইল পুরোনো গ্রুপেই থাকবে)।

    লিংকে যে ডোমেইন দেখাবে। খালি রাখলে Render-এর ঠিকানা ব্যবহার হবে।

    Render ইন্টিগ্রেশন (স্থায়ী সেভ)

    Render-এর ডিস্ক অস্থায়ী — রিস্টার্টে ফাইল মুছে যায়। Render API Key দিলে প্যানেলে বদলানো API ID/Hash, টোকেন, গ্রুপ আইডি ও পাসওয়ার্ড নিজে নিজেই Render Environment-এ সেভ হবে, তাই রিস্টার্টেও হারাবে না।

    Render → Account Settings → API Keys → Create API Key।
    Render-এ চললে নিজে থেকেই ধরে নেয়। না পেলে সার্ভিসের URL থেকে srv-… অংশ দিন।
