# ☁️ Ay File Host v2

Render-এ শুধু হোস্টিং, ফাইল থাকে আপনার **টেলিগ্রাম গ্রুপে**। Render-এর ডিস্কে কিছুই জমে না — আপলোড সরাসরি টেলিগ্রামে স্ট্রিম হয়, ডাউনলোডও টেলিগ্রাম থেকে স্ট্রিম হয়ে আসে।

লিংক: `https://your-app.onrender.com/f/123-a1b2c3d4e5/photo.jpg` — শেষে সবসময় আসল ফরম্যাট (`.html`, `.apk`, `.png` …)। গ্রুপ থেকে মেসেজ ডিলিট করলে লিংক অচল।

## v2-তে কী নতুন
- **API ID, API Hash, বট টোকেন, গ্রুপ আইডি — সবই প্যানেল থেকে** সেট/বদল করা যায় (কোডে বা Environment-এ লাগবে না)
- প্রথমবার ঢুকলে নিজের পাসওয়ার্ড বানাতে হয় (ডিফল্ট `1234` আর নেই)
- নতুন ড্যাশবোর্ড: সেটআপ গাইড, কানেকশন হেলথ চেক (বটের Post/Delete/Pin অনুমতিসহ), আপলোড/ডাউনলোড কাউন্টার
- সেটিংস: সাইটের নাম, থিম রঙ, সাইজ লিমিট, সমান্তরাল আপলোড, নিষিদ্ধ এক্সটেনশন, ক্যাশ সময়, ক্যাপশন, HTML স্যান্ডবক্স, লগইন লক/সেশন মেয়াদ, কাস্টম ডোমেইন, API অন/অফ, সব ডিভাইস লগআউট
- Render API Key দিলে প্যানেলের সব সেটিং Render Environment-এ নিজে সেভ হয় (রিস্টার্টে হারায় না)
- সার্ভার লগ ভিউয়ার ও রিস্টার্ট বাটন; API দিয়ে আপলোড/তালিকা/ডিলিট
- ফিক্স: পুরোনো কোডে `os.getenv("39102820")` ভুলভাবে API ID পড়ছিল ও API Hash কোডে লেখা ছিল — এখন কোডে কোনো সিক্রেট নেই; ফাইল লিস্টের পেজিনেশন ও CSRF সুরক্ষা ঠিক করা হয়েছে

## সেটআপ (৫ মিনিট)
1. **GitHub-এ আপলোড** করুন এই ফোল্ডার → Render → New → **Web Service**
   - Build: `pip install -r requirements.txt`  ·  Start: `python server.py`
   - Environment: `PYTHON_VERSION=3.11.9` এবং **`ADMIN_PASSWORD=<আপনার পাসওয়ার্ড>`** (প্রস্তাবিত — তাহলে অন্য কেউ আগে ঢুকে পাসওয়ার্ড বানাতে পারবে না; ভুলে গেলে এটাই রিকভারি)
2. ডিপ্লয় হলে সাইট খুলুন → লগইন (ADMIN_PASSWORD দিলে সেটা; না দিলে প্রথমবার নতুন পাসওয়ার্ড বানান)
3. **সেটিংস → টেলিগ্রাম**-এ দিন:
   - **API ID ও API Hash** — https://my.telegram.org → API development tools
   - **বট টোকেন** — @BotFather
   - **গ্রুপ আইডি** — প্রাইভেট গ্রুপ বানিয়ে বটকে অ্যাডমিন করুন (Post, Delete, Pin অনুমতি); আইডি পেতে গ্রুপের মেসেজ @getidsbot-এ ফরওয়ার্ড করুন (`-100…`)
4. **সেটিংস → সার্ভার**-এ **Render API Key** দিন (Render → Account Settings → API Keys) — এতে সব মান স্থায়ীভাবে সেভ হবে।
5. ড্যাশবোর্ডে **পরীক্ষা করুন** চাপলে সব ✓ দেখা উচিত।

## সেটিংস কোথায় সেভ হয়
| কী | কোথায় |
|---|---|
| API ID/Hash, বট টোকেন, গ্রুপ আইডি, পাসওয়ার্ড হ্যাশ, পাবলিক URL | `data/state.json` (অস্থায়ী ডিস্ক) + Render Environment (Render API Key থাকলে) |
| সাইট সেটিংস, লিংক সিক্রেট, API কী | টেলিগ্রাম গ্রুপের **পিন করা এনক্রিপ্টেড মেসেজ** (বট টোকেন থেকে বানানো কী) |

> Render API Key না দিলে প্রথম ধরনের মান রিস্টার্ট/রিডিপ্লয়ে হারাতে পারে — তখন Render Environment-এ `API_ID`, `API_HASH`, `BOT_TOKEN`, `GROUP_ID` নিজে বসাতে হবে। Render API দিয়ে সেভ হলে Render একবার রিডিপ্লয় করতে পারে।
>
> বট টোকেন বদলালে প্যানেল নিজেই সেটিংস মেসেজ নতুন কী দিয়ে আবার এনক্রিপ্ট করে। BotFather-এ টোকেন revoke করে সার্ভার বন্ধ থাকা অবস্থায় নতুন টোকেন বসালে সেটিংস মেসেজ পড়া যায় না — তখন লিংক সিক্রেট/API কী নতুন তৈরি হবে (পুরোনো লিংক অচল হবে)। তাই আগে প্যানেল থেকে টোকেন বদলান।

## API
```
curl -X PUT "https://your-app.onrender.com/api/upload" \
  -H "X-API-Key: <প্যানেলের API কী>" \
  -H "X-Filename: app.apk" \
  --data-binary @app.apk
```
`GET /api/files?limit=30&before=0` ও `DELETE /api/files/<id>` — একই `X-API-Key` হেডার। (প্যানেলের API ট্যাবে Python/JS উদাহরণ আছে।)

## জেনে রাখুন
- ডাউনলোড-আপলোডের ডেটা Render-এর **ব্যান্ডউইথ** দিয়ে যায় (ফ্রি প্ল্যানে মাসিক সীমা আছে)।
- ফ্রি প্ল্যানে ১৫ মিনিট অ্যাক্টিভিটি না থাকলে সার্ভার ঘুমায়; Keep-alive অপশন নিজেকে পিং করে, চাইলে Uptime বটও ব্যবহার করুন।
- ড্যাশবোর্ডের ফাইল সংখ্যা/সাইজ সাম্প্রতিক মেসেজ স্ক্যান করে বের হয় (বড় গ্রুপে `+` চিহ্ন দেখায়)।
- আগের zip-এ আপনার API ID/Hash কোডে লেখা ছিল — সেই zip কারো সাথে শেয়ার করে থাকলে my.telegram.org থেকে নতুন API Hash নেওয়া ভালো।
